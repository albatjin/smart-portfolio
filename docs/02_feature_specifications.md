## 2. 상세 기능 명세 (Detailed Specifications)

### [FEAT-01] AI 인터뷰 온보딩 & 포트폴리오 자동 빌더 (P0)
- **개념**: 빈 양식을 작성할 필요 없이, 창작자가 Gemini AI의 인터뷰 질문에 음성/채팅으로 답하면 웹사이트 콘텐츠와 챗봇 지식 베이스를 자동 생성.
- **인터뷰 질문 세트 (5~7문)**:
  1. 기본 정체성: *"어떤 비즈니스(또는 창작 작업)를 전문으로 하시나요?"*
  2. 주요 고객/분야: *"주로 어떤 고객이나 업종과 작업을 많이 진행하셨나요?"*
  3. 대표 프로젝트: *"가장 자랑하고 싶은 대표 작업 2~3가지의 이름과 성과를 말씀해 주세요."*
  4. 협업 원칙 및 강점: *"고객이 다른 곳이 아닌 작가님을 선택해야 하는 가장 큰 강점은 무엇인가요?"*
  5. 룰북 설정: *"최소 프로젝트 수주 단가와 기본 작업 소요기간은 어떻게 되시나요?"*
- **사용자 시나리오**:
  - `창작자 가입` ➔ `[AI 인터뷰 시작]` 클릭 ➔ `Gemini 대화 진행` ➔ `JSON 데이터 파싱` ➔ `포트폴리오 미리보기 렌더링` ➔ `간단 수정 후 발행`.

### [FEAT-02] RAG 대화형 AI 어시스턴트 & 무관 질문 방어 가드레일 (P0)
- **개념**: 방문자가 포트폴리오 사이트에서 AI 챗봇에게 질문하면 등록된 프로젝트 및 창작자 지식을 검색하여 팩트 기반으로 답변.
- **무관한 질문 방어 가드레일 (Out-of-scope Guardrail)**:
  - 포트폴리오, 작업 이력, 스타일, 견적, 협업과 관련 없는 질문(일반 상식, 날씨, 정치, 타 주제, 탈옥 시도 등) 유입 시 정형화된 거절 및 대화 유도 메시지 출력.
  - **정형 방어 메시지 템플릿**:
    > *"죄송합니다. 저는 [창작자명] 작가님의 포트폴리오 및 프로젝트 의뢰와 관련된 질문에만 답변드릴 수 있습니다. 작가님의 작업 이력, 단가, 협업 방식 등에 대해 궁금하신 점이 있으시다면 언제든 말씀해 주세요!"*
- **사용자 시나리오**:
  - 방문자: *"유사한 F&B 브랜드 로고 제작 사례가 있나요?"* ➔ AI: *"네, 작가님은 '카페 모던'과 '베이커리 르보'의 브랜딩 작업을 진행하셨습니다. 화면의 프로젝트 카드를 클릭하시면 상세 이미지를 보실 수 있습니다."*
  - 방문자: *"오늘 서울 날씨 어때?"* ➔ AI: (위 정형 방어 메시지 출력)

### [FEAT-03] 사전 단가/일정 룰북 기반 24/7 AI 견적 스크리닝 (P0)
- **개념**: 창작자가 관리자 페이지에서 설정한 **최소 단가(min_budget), 최소 제작기간(min_duration_days), 불가 작업 유형(blocked_requests)** 가드레일을 준수하여 견적 문의를 스크리닝.
- **사용자 시나리오**:
  - 방문자: *"30만 원에 3일 만에 작업 가능한가요?"*
  - AI: *"작가님의 최소 프로젝트 단가는 80만 원부터 시작하며, 기본 제작 기간은 최소 2주가 소요됩니다. 3일 급행 작업은 진행이 어렵습니다. 해당 조건 범위 내에서 정식 협의를 원하시면 의뢰서를 남겨주세요."*

### [FEAT-04] 카카오톡 알림톡 기반 실시간 의뢰서 전달 (P0)
- **개념**: AI와 상담을 마친 방문자가 의뢰 의사를 밝히면 AI가 요구사항을 정제하여 창작자 카카오톡으로 즉시 전송.
- **의뢰서 수집 항목**:
  - 의뢰인 이름 / 소속
  - 연락처 (휴대폰 번호 필수)
  - 프로젝트 분야 및 핵심 요구사항 요약
  - 희망 예산 및 마감일
  - 전체 대화 요약문
- **발송 포맷 (알림톡 예시)**:
  ```
  🔔 [InterFolio] 새로운 프로젝트 의뢰가 도착했습니다!
  • 의뢰인: 홍길동 (스타트업 A)
  • 요청작업: 신규 F&B 브랜드 로고 디자인
  • 희망예산: 150만 원 / 마감희망: 3주 이내
  • 연락처: 010-1234-5678
  👉 [상세 의뢰서 및 전체 대화로그 보기](링크)
  ```

### [FEAT-05] 4종 테마 프리셋 & 고유 서브도메인 (P0)
- **개념**: 별도의 복잡한 웹 빌더 없이 클릭 한 번으로 완벽하게 반응하는 4종 테마 선택 지원.
- **테마 프리셋 목록**:
  1. `Modern Dark`: 테크, 개발자, 미디어 에이전시 특화 (다크 모드 기본, 모던 블루 포인트)
  2. `Clean White`: 미니멀 컨설턴트, 마케터, 비즈니스 특화 (화이트 배경, 타이포그래피 강조)
  3. `Agency Magazine`: 브랜딩, 디자인, 포토그래퍼 특화 (그리드 레이아웃, 시각 이미지 극대화)
  4. `Warm Studio`: 공방, 인테리어 시공, 1인 제작자 특화 (따뜻한 베이지/어스톤 톤앤매너)
- **고유 URL**: `interfolio.me/@username` 형태의 퍼블릭 링크 자동 부여.

### [FEAT-06] 관리자 대시보드 & 인가 이메일 기반 엄격한 접근 제어 (P0)
- **개념**: 창작자가 본인의 포트폴리오를 수정하고 수집된 의뢰서 목록을 열람하는 관리자 페이지(`/admin` 또는 `/dashboard`).
- **접근 제어 정책 (RBAC & Auth Guard)**:
  - 사전에 지정된 인가 관리자 이메일(또는 해당 포트폴리오 소유자 이메일)로 로그인된 활성 세션만 접근 허용.
  - 비인가 계정 또는 비로그인 상태로 `/admin` 진입 시:
    - 즉시 `/login?redirect=/admin`으로 강제 리다이렉트.
    - 로그인 후에도 인가 목록에 없는 이메일일 경우 **403 Forbidden ("접근 권한이 없는 계정입니다")** 에러 화면 표출.
- **핵심 관리 기능**:
  - 내 포트폴리오 정보 및 프로젝트 추가/삭제/수정
  - 단가/일정 룰북 값 변경
  - 수신된 의뢰서 목록 (상태: 신규 접수 / 상담 진행 / 계약 완료) 칸반 및 연락처 열람

### [FEAT-07] 유료 프로 패키지 (P1 - 추후 확장)
- **개념**: 서비스 지속 가능성을 위한 B2B/B2C SaaS 수익화 패키지.
- **주요 혜택**:
  - 개인 커스텀 도메인(`mybrand.com`) 연결 지원
  - 웹사이트 하단 "Powered by InterFolio" 뱃지 제거
  - 월간 방문자 질문 트렌드 및 유입 분석 리포트 제공
