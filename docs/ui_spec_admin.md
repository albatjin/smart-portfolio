## 1. 레이아웃 구조 (Layout Structure)

화면 정중앙에 위치한 카드 형태의 독립된 로그인 컨테이너 (Centered Card Layout).

```text
┌────────────────────────────────────────────────────────┐
│                        [배경]                          │
│         ┌────────────────────────────────────┐         │
│         │ 🛡️ InterFolio Admin                │         │
│         │ 관리자 계정으로 로그인해 주세요.        │         │
│         ├────────────────────────────────────┤         │
│         │ 이메일:   [ admin@creator.com    ] │         │
│         │ 비밀번호: [ •••••••••••••        ] │         │
│         │                                    │         │
│         │ [      관리자 로그인하기         ] │         │
│         ├────────────────────────────────────┤         │
│         │ ⚠️ 특정 인가된 관리자 이메일 계정만  │         │
│         │    접근이 허용됩니다.              │         │
│         └────────────────────────────────────┘         │
└────────────────────────────────────────────────────────┘
```

## 2. 세부 명세 및 접근 제어 정책

### 2.1 입력 필드 및 버튼
- **이메일 필드**:
  - 라벨: `관리자 이메일` (`type="email"`, Placeholder: `admin@example.com`)
  - 자동 포커스 및 이메일 정규식 유효성 검사 적용
- **비밀번호 필드**:
  - 라벨: `비밀번호` (`type="password"`, 우측 비밀번호 보기/숨기기 눈 모양 아이콘 제공)
- **로그인 버튼**:
  - 스타일: `w-full py-3 bg-primary text-primary-foreground font-semibold rounded-lg hover:opacity-90 transition-all`
  - 로딩 상태: 로그인 인증 중 스피너 표시 및 버튼 비활성화

### 2.2 [PRD 필수 조건] 특정 이메일 접근 제어 정책 (Security Guardrail)
1. **인가 이메일 대조 (Whitelist Verification)**:
   - Supabase Auth 인증 통과 후, 해당 사용자의 이메일이 환경 변수(`ALLOWED_ADMIN_EMAILS`) 목록에 등록되어 있는지 서버 사이드에서 검증.
2. **비인가 이메일 로그인 시도 시 (Access Denied)**:
   - 인증 세션을 즉시 무효화(`supabase.auth.signOut()`)하고 경고 알림 표시:
     > **에러 메시지**: *"접근 권한이 없는 계정입니다. 사전에 등록된 관리자 전용 이메일로 로그인해 주세요."*
3. **인증 성공 시**:
   - 관리자 메인 대시보드인 **`/admin`**으로 즉시 리다이렉트.

# PART 2. 관리자 대시보드 (`/admin`)

## 1. 레이아웃 구조 (Layout Structure)

좌측 고정 사이드바(Sidebar) + 우측 메인 콘텐츠 패널(Main Content)로 구성된 전형적인 2열 관리자 레이아웃.

```text
┌──────────────────┬─────────────────────────────────────────────────────────┐
│ [Brand/Logo]     │ [Top Bar] 👤 관리자님 (admin@creator.com)   [로그아웃]    │
│ 🛡️ Admin Studio  ├─────────────────────────────────────────────────────────┤
├──────────────────┤ [Content Header] 선택된 탭 제목 (예: 프로젝트 관리)       │
│ [Sidebar Menu]   │                                                         │
│ 👤 프로필 관리    │ [Main Dynamic Panel]                                    │
│ 📁 프로젝트 관리* │  - 프로필 관리 폼                                        │
│ 🤖 챗봇 데이터 관리│  - 또는 프로젝트 목록 테이블 + [추가] 버튼                 │
│ 📋 수신 의뢰서   │  - 또는 챗봇 지식/룰북 관리 목록                          │
├──────────────────┤                                                         │
│ [Footer Status]  │                                                         │
│ Vercel + Supabase│                                                         │
└──────────────────┴─────────────────────────────────────────────────────────┘
```

---

## 2. 세부 탭별 상세 명세 (Tab Details)

### 2.1 좌측 사이드바 (Navigation Sidebar)
- **너비**: 데스크톱 `240px` 고정 (`w-60 border-r bg-card flex flex-col justify-between p-4`)
- **메뉴 항목**:
  1. `👤 프로필 관리` (`active` 시 `bg-primary/10 text-primary font-semibold`)
  2. `📁 프로젝트 관리`
  3. `🤖 챗봇 데이터 관리`
  4. `📋 수신 의뢰서 (Leads)` (미확인 의뢰 뱃지 알림)
- **하단 유틸리티**:
  - 사용자 계정 정보 (`admin@creator.com`) + `[로그아웃]` 버튼 (`text-destructive`)

---

### 2.2 [탭 1] 프로필 관리 (Profile Management Form)
창작자의 기본 정보, 소개, 스킬, 경력을 수정하여 메인 페이지(`/`)에 즉각 반영하는 폼.

- **기본 소개 영역**:
  - 이름 / 활동명 (Text Input)
  - 전문 직군 타이틀 (예: `1인 인테리어 디렉터`, `브랜드 디자이너`)
  - 한 줄 소개문 (Text Input) 및 상세 자기소개 (Textarea, 4줄)
  - 대표 프로필 이미지 (200×200 미리보기 + 이미지 교체 업로드 버튼)
- **스킬(Skills) 관리 영역**:
  - 보유 스킬 태그 리스트: 각 태그마다 `[X]` 삭제 버튼 제공
  - 새 스킬 추가 인풋: 텍스트 입력 후 `Enter` 또는 `[추가]` 클릭 시 즉시 뱃지 추가
- **경력(Experience) 관리 영역**:
  - 타임라인 항목 목록: `연도 | 회사명 | 역할 | 설명` 카드 리스트
  - 각 항목별 `[수정]`, `[삭제]` 버튼 및 하단 `[+ 새 경력 추가]` 버튼
- **하단 액션 바**:
  - `[변경사항 저장하기]` (Primary Button) ➔ 클릭 시 Supabase `profiles` 테이블 업데이트 및 토스트 알림("프로필이 성공적으로 저장되었습니다.")

---

### 2.3 [탭 2] 프로젝트 관리 (Project Management Table & Modal)
포트폴리오에 노출될 프로젝트 목록을 확인하고 CRUD(생성/조회/수정/삭제)를 수행.

- **상단 툴바**:
  - 프로젝트 총 개수 카운트 (`총 6개의 프로젝트`)
  - 우측 액션: **`[+ 새 프로젝트 추가]`** 메인 버튼
- **프로젝트 목록 테이블 (Table UI)**:
  - **컬럼 구성**: `썸네일(60x40)` | `프로젝트 제목` | `카테고리` | `사용 기술` | `등록일` | `관리(수정/삭제)`
  - **행 액션**:
    - `[수정]` 클릭: 해당 프로젝트 데이터가 채워진 수정 모달 팝업
    - `[삭제]` 클릭: 확인 경고 팝업 *"정말 이 프로젝트를 삭제하시겠습니까?"* 표출 후 삭제 처리
- **[팝업 모달] 프로젝트 추가 / 수정 모달 (Project Modal)**:
  - 크기: `max-w-2xl w-full rounded-2xl bg-card p-6 shadow-2xl`
  - **입력 필드**:
    1. `프로젝트 제목`: (예: 카페 모던 브랜드 아이덴티티)
    2. `카테고리 선택`: 드롭다운 (`웹`, `앱`, `디자인`, `브랜딩`, `시공/인테리어`, `기타`)
    3. `간략 설명`: 카드용 요약 (2줄 이내)
    4. `상세 설명`: 상세 페이지(`/project/[id]`) 본문용 마크다운 텍스트에어리어
    5. `대표 이미지 업로드`: 드래그앤드롭 파일 업로더 (Supabase Storage 연동, 16:9 미리보기)
    6. `사용 기술 태그`: 쉼표(,) 구분 입력 (예: `Figma, Illustrator, Branding`)
    7. `관련 링크 URL`: 라이브 데모 URL, GitHub URL, 피그마 링크 등
  - **하단 버튼**: `[취소]` 및 `[프로젝트 저장하기]`

---

### 2.4 [탭 3] 챗봇 데이터 관리 (AI Chatbot Knowledge & Rulebook)
포트폴리오 AI 챗봇이 방문자에게 답변할 때 참조하는 **지식 베이스(KB)**와 **단가/일정 룰북**을 설정하는 핵심 패널.

- **섹션 A: 단가 및 협업 룰북 설정 (Rulebook Settings)**:
  - `최소 수주 단가`: (예: `800,000` 원) ➔ 이 금액 미만의 의뢰는 AI가 1차 거절
  - `기본 제작 소요기간`: (예: `14` 일) ➔ 무리한 단기 일정 요청 거절 기준
  - `수주 불가 작업 키워드`: 태그 형태 등록 (예: `무료 시안`, `사후 정산`, `불법 카피`)
- **섹션 B: 자주 묻는 질문(FAQ) 및 챗봇 참조 데이터 목록 (Knowledge Base)**:
  - **목록 테이블**: `구분` | `질문(Key)` | `AI 답변 가이드(Content)` | `관리`
    - *예시 1*: `[견적/단가]` - "로고 디자인 기본 비용이 어떻게 되나요?" ➔ "기본 시안 3종 기준 80만 원부터 시작합니다."
    - *예시 2*: `[작업방식]` - "수정은 몇 번까지 가능한가요?" ➔ "기본 3회 무료 수정이 제공됩니다."
    - *예시 3*: `[연락방법]` - "전화 상담이 가능한가요?" ➔ "의뢰서를 남겨주시면 작가님이 1시간 내로 직접 전화드립니다."
  - **데이터 추가/수정 모달**:
    - 카테고리 태그 선택 + 질문 입력 + AI 표준 답변 내용 입력 + `[저장]`
    - 저장 시 자동으로 텍스트 임베딩이 생성되어 Supabase `pgvector`에 실시간 업데이트.

## 3. 반응형 동작 명세 (Responsive Behavior)

| 구분 | 모바일 (Mobile, < 768px) | 데스크톱 (Desktop, ≥ 1025px) |
| :--- | :--- | :--- |
| **사이드바 메뉴** | • 기본 숨김 처리<br>• 상단 바 좌측 햄버거 메뉴 버튼 터치 시 오버레이 드로어로 전개 | • 좌측 `240px` 폭으로 영구 고정 노출<br>• 콘텐츠 영역과 분리 |
| **프로젝트 테이블** | 가로 스크롤 허용(`overflow-x-auto`) 또는 카드형 리스트로 전환 | 넓은 화면을 활용한 완전한 테이블 그리드 렌더링 |
| **추가/수정 모달** | 모바일 바텀시트(Bottom Sheet) 형태로 하단에서 슬라이드 업 | 화면 중앙에 정렬되는 둥근 다이얼로그 모달 |
| **룰북/프로필 폼** | 1열 수직으로 입력 필드 순차 배치 | 2열 그리드(Grid 2 cols)로 여유 있는 입력 폼 배치 |
