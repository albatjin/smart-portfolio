## 🎯 MVP (최소 기능 제품) 정의 및 판정 기준

사용자가 즉시 포트폴리오를 배포하고 가치를 검증할 수 있는 **MVP 4대 핵심 기준**:
1. **메인 페이지가 보인다** (프로필 사진, 소개, 스킬, 경력 타임라인)
2. **작품 갤러리가 작동한다** (카테고리 필터, 프로젝트 카드 그리드, 상세 페이지)
3. **AI 챗봇이 기본적인 질문에 답변한다** (프로젝트 이력, 전문 분야, 단가/일정 질의응답 및 무관 질문 방어)
4. **관리자가 데이터를 추가/수정할 수 있다** (인가 로그인, 프로필/스킬 수정, 프로젝트 CRUD 모달)

> **구분 표기 안내**:
> - **`[MVP]`**: 최소 기능 제품 출시에 필수적인 핵심 작업 (1차 런칭 목표)
> - **`[확장]`**: MVP 런칭 후 순차적으로 고도화할 부가 기능 (알림톡, CRM, 인앱 최적화 등)
